# Common Networking Terms

The following networking terms have been explained in brief:
    1. Bandwidth
    2. Latency
    3. Throughput
    4. Jitter
    5. Packet Loss

# Bandwidth

Bandwidth is defined as the maximum rate at which data can be transmitted over a network connection. It represents the maximum capacity of the communication channel.
It is represented in Bits per second (bps) and its higher denominations.
A higher bandwidth allows faster downloads, faster uploads, larger file transfers and streaming and better performance for multiple users.

# Latency

Latency is defined as the amount of time taken by a packet of data to travel from the source device to the destination device. It is also known as network delay. It is measured in milliseconds(ms). 
A lower value is better. Minimising latency is critical for online gaming, video conferencing, remote desktop connections and financial trading systems.
High latency results in noticeable delays, making  applications feel slow and/or unresponsive.

# Throughput

Throughput is the actual rate at which data is successfully transferred over a network.
Bandwidth measures the theoretical capacity of a network, whereas throughput represents the true performance of the network. Throughput takes into consideration network congestion, packet loss, latency, hardware performance and wireless interference.

# Jitter

Jitter is defined as the variation in packet arrival times. Ideally, packets arrive at regular intervals. Fluctuation in their arrival times are known as jitter.
It is measured in milliseconds (ms). A lower jitter is preferred. Higher jitter causes choppy audio, frozen video, distorted calls and video game lags.

# Packet Loss

Packet loss occurs when one or more packets fail to reach their destination; the packets are dropped somewhere along the transmission path.
It can be caused by faulty hardware, router failures, software bugs, network congestion, etc.
Packet loss is usually expressed in percentage (%) of packets lost.
High packet loss can lead to slow downloads, game lag, buffering and interrupted voice and video calls.
