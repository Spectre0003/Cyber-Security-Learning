# Types of Network Media

Network media refers to the path through which data travels(physical or wireless).
It is divided broadly into two types:
    1. Guided Media
    2. unguided Media

# Guided Media

Guided media refers to physical medium through which data travels, that is using physical cables. Most used guided media are as follows:
    1. Twisted Pair Cable
    2. Coaxial Cable
    3. Fiber Optic Cable

# Unguided Media

Unguided media refers to the electromagnetic signals through which data travels. They need not require any phycial media to travel. Examples include:
    1. Wi-Fi
    2. Bluetooth
    3. Radio Waves
    4. Satellite Communication
